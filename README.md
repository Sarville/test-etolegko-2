# Keitaro Campaign Studio

Приложение для создания кампаний и управления офферами потоков Keitaro. FastAPI + SQLAlchemy + SQLite, интерфейс React + Vite.

## Запуск

1. В `.env` укажите `API_URL=https://ваш-сервер/admin_api/v1` и `API_KEY=ключ`. Завершающий слеш допустим.
2. В первом терминале:
   ```bash
   python3 -m venv .venv
   .venv/bin/pip install -r requirements.txt
   .venv/bin/uvicorn backend.main:app --reload
   ```
3. Во втором терминале:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
4. Откройте адрес Vite, обычно http://localhost:5173.

## Как работает

Кампания создаётся в существующей группе FORTESTS; источник FORTESTS выбирается, если он существует. Если в Keitaro один активный домен, он прикрепляется к кампании; иначе используется настройка трекера по умолчанию. Первый поток отправляет выбранное гео на `https://google.com`, второй — на оффер. При ошибке создания потока интерфейс покажет ID частично созданной кампании для проверки в Keitaro.

Редактор загружает все потоки кампании. Потоки со схемой посадочных страниц и офферов доступны для редактирования; остальные отображаются информационно. Изменения находятся в черновике до нажатия Push to KT. Доли незакреплённых офферов распределяются поровну в целых процентах. Удалённый оффер хранится локально и доступен для восстановления. Fetch from KT обновляет состав потока; отсутствующие офферы остаются доступными для восстановления. Если состав изменился, доли пересчитываются в черновике и требуют отправки. При конфликте внешних изменений отправка отклоняется: обновите данные кнопкой Fetch from KT.

Закрепления и история удалённых офферов сохраняются в `keitaro.db` на сервере приложения. База локальна для данной установки. Значок закрепления хранится приложением, а не Keitaro. Статистика и тренды не используются.
