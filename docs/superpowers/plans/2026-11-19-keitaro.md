# План реализации интеграции Keitaro

Цель: создание кампаний и редактирование офферов второго потока через FastAPI, SQLAlchemy и React.

1. Подключить Keitaro Admin API по API_URL и API_KEY, обрабатывать ошибки, не раскрывать ключ.
2. Создавать кампанию в группе FORTESTS с двумя потоками: геофильтр и редирект на Google; запасной поток с выбранным оффером. Домен и источник — существующие настройки трекера.
3. Хранить локальную историю удалённых офферов и закрепления в SQLite. Получать поток из Keitaro; синхронизация сохраняет отсутствующие офферы как удалённые.
4. В редакторе создавать черновик, равномерно перераспределять целочисленные доли среди незакреплённых, поддерживать восстановление, отмену и отправку с проверкой изменений на сервере.
5. Проверить распределение, синхронизацию, формирование запросов и сборку интерфейса; описать запуск и ограничения интеграции.
